# Memory: features/products/composite-creation-workflow
Updated: 2026-01-21

Composite products follow a two-step creation process: (1) Define the composite product container with its own general name, details, and input/output fields (prompts/outputs) without components; (2) Select the created product and add one or more existing EasyQuote components (products marked with 'is_component: true') to it. This allows for flexible nesting of multiple distinct EasyQuote products/Excels within a single composite product.
