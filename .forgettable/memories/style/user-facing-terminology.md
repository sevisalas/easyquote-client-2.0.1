# Terminología para Usuario Final

## Regla Crítica
En la interfaz de usuario NUNCA se usan los términos técnicos:
- ❌ "Prompts" → ✅ "Datos de entrada", "Opciones", "Campos"
- ❌ "Outputs" → ✅ "Resultados", "Datos calculados", "Información"

## Contexto
Los términos "prompts" y "outputs" son internos del sistema (API EasyQuote). 
Para el usuario final, estos conceptos deben presentarse con nombres descriptivos y amigables.

## Ejemplos de uso
- "Configura los datos de entrada del producto"
- "Resultados del cálculo"
- "Opciones del artículo"

## Abreviaturas internas (desarrollo)
- **EQAPI** = EasyQuote API — el servicio cloud de cálculo, productos y excels
- **EQAPP** = EasyQuote APP — la aplicación cliente que estamos desarrollando

Estas abreviaturas son solo para comunicación interna entre desarrolladores. NO se usan en la UI.
